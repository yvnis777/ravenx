# RavenX — Frontend

Next.js app for RavenX. See the [root README](../README.md) for what RavenX is and how to run the whole stack, and [`ARCHITECTURE.md`](ARCHITECTURE.md) for architecture and conventions.

```bash
cp .env.example .env.local
npm install
npm run dev        # http://localhost:3000
npm run test:run   # tests
npx tsc --noEmit   # type check
```
